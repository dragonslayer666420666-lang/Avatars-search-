How it works

          
1. Avatar Search opens a GitHub issue beginning with [Construction Bot].

          
2. GitHub Actions reads the request and prepares an exact patch for index.html.

          
3. The bot validates the changed file and creates a separate pull request.

          
4. You review the pull request and choose whether to merge it.

          
Never put API keys, passwords, access tokens, or private information in a Construction Bot request.
